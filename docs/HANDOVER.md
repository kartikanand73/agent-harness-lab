# Starter handover

Delivered: working local expense API, SQLite schema, baseline tests, CI definition,
repository instructions, one active task, three backlog briefs, and an independent
H001 acceptance check. The enhancement implementations are intentionally absent.

Prerequisites: Python 3.11+, Git, a GitHub repository, and a local Claude harness
with the permissions needed to clone and push a feature branch. No API key or
model subscription is needed to run the application itself.

Start with README.md. Run the baseline. Then give your harness Task.md and let
it work on H001. Inspect the resulting PR and test evidence before merging.
Repeat with H002, H003, and H004 only after each preceding task is merged.

This starter is an exercise in creating a customer-owned development workflow;
it is not itself a production harness, expense product, or verified customer ROI.
